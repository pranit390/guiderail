# Creating a Cloud Storage bucket

The user clicks Create. Guide stops before it. Source: https://cloud.google.com/storage/docs/creating-buckets

1. Open Cloud Storage > Buckets and click Create.
2. Name the bucket. Names are global and public, so no personal data. Source: https://cloud.google.com/storage/docs/buckets#naming
3. Choose a location type. Region is cheapest when one region is enough.
4. Keep the Standard storage class unless the user says the data is rarely read.
5. Keep "Enforce public access prevention" on and choose Uniform access control (recommended). Source: https://cloud.google.com/storage/docs/uniform-bucket-level-access
6. Stop before Create. The user reviews and clicks Create themselves.
